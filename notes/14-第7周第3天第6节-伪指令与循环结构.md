## 关键概念

### 1. MIPS 伪指令的本质

MIPS 指令集"精简"的代价：很多看似基本的功能需要多条指令拼合：

| 伪指令 | 实际展开 | 说明 |
|---|---|---|
| `blt $1, $2, label` | `slt $at, $1, $2` + `bne $at, $zero, label` | `$at`=汇编器保留寄存器（assembler temporary） |
| `bgt $1, $2, label` | `slt $at, $2, $1` + `bne $at, $zero, label` | 交换操作数取反逻辑 |
| `ble $1, $2, label` | `slt $at, $2, $1` + `beq $at, $zero, label` | |
| `bge $1, $2, label` | `slt $at, $1, $2` + `beq $at, $zero, label` | |
| `move $rd, $rs` | `add $rd, $rs, $zero` | |
| `li $rd, imm` | `addi $rd, $zero, imm` 或 `lui`+`ori`（超出 16 位时） | 立即数加载 |

MIPS 硬件只提供了 `slt`/`slti`（置 0/1）+ `beq`/`bne`，所有大小比较+跳转均由汇编器合成。

### 2. 函数调用的寄存器约定（MIPS ABI）

**参数寄存器**：`$a0-$a3`（4 个）。超过 4 个参数必须压入调用者的栈帧。
**返回值寄存器**：`$v0-$v1`（2 个）。
**返回地址寄存器**：`$ra`（`$31`）。`jal` 指令自动写 `$ra = PC+4`，返回用 `jr $ra`。
**栈指针**：`$sp`（`$29`）。向低地址增长。

**调用者保存寄存器**（caller-saved）：`$t0-$t9`、`$a0-$a3`、`$v0-$v1`。调用者若需在函数返回后继续使用这些值，需自行压栈保存。
**被调用者保存寄存器**（callee-saved）：`$s0-$s7`、`$ra`、`$sp`。被调用函数若使用这些寄存器，必须先保存原值，返回前恢复。

**优先使用调用者保存寄存器**的原因：调用者可能已经不需要这些值了，被调用函数直接用即可，省去保存/恢复的开销。

### 3. 嵌套调用时的栈帧操作

递归或嵌套调用场景下，`$ra` 和 `$a0-$a3` 会被覆盖：
```
sum_square:
    addi $sp, $sp, -8      # 开 8 字节栈帧
    sw   $ra, 4($sp)       # 保存返回地址
    sw   $a1, 0($sp)       # 保存将被覆盖的参数
    # ... 调用另一个函数 ...
    lw   $a1, 0($sp)       # 恢复参数
    lw   $ra, 4($sp)       # 恢复返回地址
    addi $sp, $sp, 8       # 回收栈帧
    jr   $ra               # 返回
```

### 4. 数据通路概念（第六章引入）

教师强调：从 CPU 设计章节起，术语从"运算器（ALU）"切换为"数据通路（datapath）"。数据通路是一个**动态概念**——指令执行过程中数据流经的所有路径与部件（含 PC、寄存器堆、ALU、存储器、多路选择器及各连接总线）。设计方法是从最简单的 R 型指令数据通路开始，逐步叠加其他指令的路径改造。

### 5. 硬布线控制器 vs 微程序控制器

- **硬布线**：直接组合逻辑→控制信号。速度快但设计复杂，指令集庞大时电路爆炸
- **微程序**：将控制信号序列编码为"微指令"存入控制存储器。相当于"用软件方式做控制器"，灵活但慢（需读控制存储器=访存）
