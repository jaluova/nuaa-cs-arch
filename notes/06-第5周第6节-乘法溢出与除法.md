## 关键概念

### 1. 乘法溢出判断（三个层次）

| 层次 | 无符号 | 有符号（补码） |
|---|---|---|
| **电路级** | n×n→2n 位，高 n 位有非零→溢出 | 高 n+1 位不全 0 且不全 1→溢出（符号位被破坏） |
| **编译器级** | 编译器可访问高 n 位结果（硬件保留了），可按电路方式判溢出 |
| **程序员级(C)** | 无符号/有符号低 n 位**完全相同**（两套电路低 n 位结果一致，差别仅在高 n 位） | 只能用逆运算 `z/x == y` 判溢出；**加减不能用逆运算判**（模运算系统丢弃高位后可能相等） |

### 2. 无符号乘与有符号乘的低 n 位等价性

n 位 × n 位 → 保留低 n 位时，无符号乘法器和有符号乘法器算出的低 n 位**完全相同**。差别仅在高 n 位。换句话说，如果你只取低 n 位结果，用哪套电路都一样。

### 3. 快速乘法（编译器优化）

编译器将"乘常数"翻译为移位+加/减组合：

- `x * 20` = `(x << 4) + (x << 2)`（16x + 4x）
- `x * 15` = `(x << 4) - x`（16x - x）
- `x * 3` = `(x << 1) + x`

**等价性保证**：移位+加/减的溢出行为与乘法指令完全一致，可以安全替换。阅读反汇编时看到移位+加法的组合应能识别出这是乘法优化。

### 4. 恢复余数→不恢复余数除法的形式化推导

**恢复余数的问题**：商 0 时已经把 y 减掉了（不够减却已减），需要加回 y→恢复→再左移。中间多了一步"恢复"，破坏了"加→移位→加→移位"的规整节奏。

**不恢复余数的推导**（本节核心方法论）：

设当前余数为 R_i：
- 若 R_i ≥ 0（商 1）：R_{i+1} = 2·R_i - y（左移后加 [-y]_{补}）
- 若 R_i < 0（商 0，原需恢复）：恢复后 R_i+y → 左移 → 减 y → 展开为 2·(R_i+y) - y = 2·R_i + y

**统一公式**：R_{i+1} = 2·R_i + (q_i==1 ? -y : +y)

也就是说：
- 商 1 → 左移 + 加 [-y]_{补}
- 商 0 → 左移 + 加 y（不再需要先恢复！）

### 5. 不恢复余数除法电路

- **两个寄存器**：R0（n+1 位，存放被除数/余数，带符号位），R1（n 位，存放商）
- **加法器输入**：2 选 1——要么加 y，要么加 [-y]_{补}（实质是可控加减电路：异或门 + 进位）
- **选择控制**：由当前商位 q_n 决定（q_n=1→加 [-y]_{补}；q_n=0→加 y）
- **c_out 与商位关系**：c_out 恰好与商位相同（因为 c_out 与余数符号位取反），因此**直接用 c_out 作为下一位商**，无需额外电路判断
- **三部分组合左移**：{和数(余数), 当前商位, c_out} → 整体左移一位 → 高位进 R0，低位进 R1
- **最后一次修正**：若最后一步 c_out=0（不够减），说明多减了 y → 需要加回 y 恢复正确余数
- **时序**：两个寄存器都需要时钟边沿锁存（时序逻辑电路）

### 6. 除数右移 vs 余数左移

手工除法中除数每次右移一位（变小），与当前被除数对齐。但在电路中，除数右移会导致位数不断增加。解决方案：**除数不动，余数左移**——效果等价，但始终保持 n 位宽度，节省寄存器开销。代价是最终余数需要**右移 n 位**恢复真实值（左移了 n 次 = 乘了 2^n）。
