## 关键概念

### 1. MIPS 跳转指令家族（容易漏）

| 指令 | 格式 | 寻址方式 | 用途 |
|---|---|---|---|
| `j target` | J 型 | 伪直接寻址（26 位×4+PC 高 4 位） | 无条件跳转 |
| `jal target` | J 型 | 同上 + 存返回地址到 `$ra` | 函数调用 |
| `jr $rs` | **R 型** | 寄存器间接寻址 | 函数返回/间接跳转 |
| `jalr $rs` | **R 型** | 寄存器间接 + 存返回地址 | 间接函数调用 |
| `beq $rs, $rt, label` | I 型 | PC 相对寻址 | 相等则跳 |
| `bne $rs, $rt, label` | I 型 | PC 相对寻址 | 不等则跳 |

MIPS 的 `beq`/`bne` 中立即数字段表示的是**跳转的指令条数**而非字节数。因为所有指令 4 字节对齐，电路会自动左移 2 位（×4）。考试写机器码时如果题目给的是汇编中的 label 标号，需计算"当前 PC+4 到目标地址相差多少条指令"填入立即数字段。

### 2. 变量分配的三级策略

- **简单变量**：优先分配在寄存器（MIPS 有 32 个通用寄存器，`$s0-$s7` 存长期变量，`$t0-$t9` 存临时变量）
- **静态变量/全局变量**：分配在内存的静态数据区
- **动态局部变量**：传统上在栈中分配；MIPS 尽量将简单局部变量也放寄存器，减少访存
- **常量**：小立即数直接用 `addi`/`ori`；大常量存在只读数据段（`.rodata`），需 `lw` 加载

### 3. 选择结构的翻译模板

C 代码 `if (a==b) { ... } else { ... }` 的 MIPS 等价：
```
        bne $s0, $s1, else_label   # 条件不满足跳 else
        # then 分支指令序列
        j end_label                  # 跳过 else
else_label:
        # else 分支指令序列
end_label:
```
注意用 `bne` 取反条件可以减少一次跳转（相比用 `beq` 需多一条 `j`）。

### 4. 使用 `$zero` 实现赋值

MIPS 没有 `mov` 指令，用 `add $rd, $rs, $zero` 实现寄存器间传送。常数值赋值用 `addi $rd, $zero, imm`。

### 5. 移位指令的细节

- `sll`/`srl`：逻辑移位（补 0）；`sra`：算术右移（补符号位）
- 没有 `sla` 指令——算术左移 = 逻辑左移（高位丢弃，低位补 0）
- shamt 字段 5 位，最多移 31 位。超范围需用可变移位版（移位量放寄存器中）
