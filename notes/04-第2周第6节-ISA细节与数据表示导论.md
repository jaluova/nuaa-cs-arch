## 关键概念

- **ISA 的 8 大组成要素**：(1) 可执行指令集合；(2) 操作数类型；(3) 寄存器组结构；(4) 编制方式；(5) 存放方式（大小端）；(6) 寻址方式；(7) 控制方式（跳转/标志位机制）；(8) 异常处理机制
- **大端 vs 小端**：多字节数据在内存中的字节序——大端（高位字节在低地址）vs 小端（低位字节在低地址）。MIPS 默认大端，x86 是小端
- **hello 执行全流程**：Shell 接收命令行 → 加载程序（loader）在硬盘找到 hello 可执行文件 → 创建进程结构 → 第一条指令地址送 PC → 操作系统退场（上下文切换） → hello 独占 CPU 逐条执行 → 执行完毕交还使用权给 Shell
- **真值**：数学上要表示的实际数值（如 $-10$）
- **机器码（机器数）**：真值在计算机中的编码表示（如 $-10$ 的 8 位补码为 `11110110`）
- **定点整数**：小数点固定在最低位之后（如 `int`, `short`）
- **定点小数**：小数点固定在最高位之前（纯小数 0.xxx），用于浮点数尾数部分的编码
- **源码表示**：符号位 + 数值位分开。问题：有 +0/-0 之分
- **补码表示**：解决符号位参与运算的问题，负数补码 = 正数按位取反 + 1
- **移码**：补码符号位取反，用于浮点数指数（阶码）编码

## 定理与公式

**源码形式化定义**（n+1 位，含符号位）：

设真值为 $X$，定点整数源码：
$$[X]_{原} = \begin{cases} X & (0 \leq X < 2^n) \\ 2^n - X & (-2^n < X \leq 0) \end{cases}$$

定点小数源码：
$$[X]_{原} = \begin{cases} X & (0 \leq X < 1) \\ 1 - X & (-1 < X \leq 0) \end{cases}$$
