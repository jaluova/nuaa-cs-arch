# 计算机组成原理 复习清单与考情分析

> 综合 2023、2024 年真题规律，按重要程度分为三档：**必考**（两年均出现）、**常考**（一年出现或高度相关）、**了解**（两年未考但属传统考点）。

---

## 一、必考（两年均出现，优先保证）

### 1. 流水线 CPU（第七章）⭐⭐⭐⭐⭐

**2023**：第四题（15分）+ 第五题（20分）= **35分**
**2024**：第四题（30分）+ 第五题（15分）+ 第一题判断 = **45分**

**必须掌握：**

- [ ] **数据冒险识别**：`R# from I# to I#` 格式写出寄存器在哪些指令间发生冲突
- [ ] **转发（Forwarding）vs 无转发**：对比两种情况下哪些数据冲突可消除
- [ ] **NOPs 插入**：无转发时最少需要几个 NOP，插入位置
- [ ] **流水线时空图**：带转发+冲突检测时，用 IF/ID/EX/MEM/WB 填表，标出气泡（stall）位置
- [ ] **ID/EX 流水寄存器**：SW/LW 等指令进入 ID/EX 时各字段的值（PC+4, Read data 1/2, 符号扩展, 控制信号等）
- [ ] **load-use 冒险**：为什么 LW 后紧跟使用同一寄存器的指令需要 1 个 stall
- [ ] 结构冒险、控制冒险的概念与解决思路
- [ ] 流水线加速比计算

**两年都考的同一道题**：SW R16, 64(R12) 填写 ID/EX 流水寄存器（2023 第四题 = 2024 第五题，原题复用）

---

### 2. Cache + 地址划分（第四章）⭐⭐⭐⭐⭐

**2023**：第六题（15分）+ 第七题（15分）= **30分**
**2024**：第六题 b/c/d（12分）+ 第一题判断

**必须掌握：**
- [ ] **主存地址划分**：Tag / Index / Block offset / Byte offset 各占哪些位
- [ ] **直接映射**：块数 → index 位数 → 地址划分
- [ ] **组相联**：组数 × 路数 → index 位数，LRU 替换
- [ ] **Cache 容量计算**（bit 为单位）：`行数 × (1 有效位 + Tag 位数 + 块大小×8)`
- [ ] **命中率 / 缺失率计算**：顺序访问模式下的冷启动缺失分析
- [ ] **平均访问时间**：`hit_time + miss_rate × miss_penalty`
- [ ] **加速比**：`无Cache时间 / 有Cache时间`
- [ ] Cache 块大小、组数变化时地址划分的重新计算

---

### 3. MIPS 汇编与指令格式（第五章）⭐⭐⭐⭐

**2023**：第三题（15分）
**2024**：第二题（15分）+ 第六题 a（3分）

**必须掌握：**

- [ ] **C → MIPS 汇编翻译**：函数调用、循环、条件判断 → 汇编（不使用伪指令）
- [ ] **R/I/J 型指令格式**：op(6) + rs(5) + rt(5) + rd(5) + shamt(5) + funct(6) / immediate(16) / address(26)
- [ ] **beq 机器码计算**：opcode + rs + rt + offset，注意 offset = (目标地址 - PC - 4) / 4 或直接数字
- [ ] **Branch 偏移计算**：loop 场景下 BEQ 的 offset 字段
- [ ] 寄存器约定：$s0-$s7, $t0-$t9, $zero, $ra 等

---

### 4. 单周期 CPU 数据通路（第六章）⭐⭐⭐⭐

**2024**：第二题（15分，beq 数据通路控制信号）

**必须掌握：**
- [ ] **控制信号表**：给定指令，填写 RegDst / ALUSrc / MemtoReg / RegWrite / MemRead / MemWrite / Branch / ALUOp
- [ ] **数据通路信号值**：Read Addr 1/2, Write Addr, Write Data, ALU 输入输出, PC 下一地址
- [ ] beq / lw / sw / R-type 各自的数据通路走向
- [ ] 单周期 CPU 中每条指令 1 个周期完成，关键路径决定时钟周期

## 二、常考（一年出现或与必考点紧密关联）

### 5. CPU 性能计算（第一章）⭐⭐⭐

**2023**：涉及在第六题 Cache 加速比中
**2024**：第三题（15分，非流水 vs 9 段流水）

**必须掌握：**
- [ ] **CPI / MIPS / 执行时间**三者关系
- [ ] 执行时间 = 指令数 × CPI × 时钟周期
- [ ] 流水线加速比：$S_p = T_{非流水} / T_{流水}$
- [ ] 流水线执行时间：$k \times T + (n-1) \times T$（k 段流水，n 条指令）

---

### 6. 虚拟存储器 / TLB（第四章）⭐⭐⭐

**2023**：第七题（15分，TLB + 页表 + Cache 综合）

**必须掌握：**
- [ ] **虚拟地址 → 物理地址**：虚页号 + 页内偏移 → 查 TLB/页表 → 物理页号 + 偏移
- [ ] **TLB 结构**：组相联，标记/索引/页框号/有效位
- [ ] TLB 命中/缺失流程
- [ ] 结合 Cache 的完整取数过程（VA → TLB → PA → Cache → 数据）

---

### 7. 有符号/无符号数运算（第二/三章）⭐⭐⭐

**2023**：第二题（10分）

**必须掌握：**
- [ ] 原码/反码/补码/移码的编码规则与转换
- [ ] 补码加减法运算过程
- [ ] 溢出判断：双符号位法、进位判断法
- [ ] MIPS 中 addu/add、subu/sub 的区别（溢出处理不同）
- [ ] 有符号数与无符号数在硬件层面如何区分（通过指令而非数据本身）

---

### 8. 程序编译执行过程（第一章）⭐⭐⭐

**2023**：第一题（10分）

**必须掌握：**
- [ ] hello.c → 预编译 → 编译 → 汇编 → 链接 → 可执行文件
- [ ] 可执行文件装入内存 → OS 创建进程 → 加载器分配地址空间 → 设置 PC → CPU 取指执行
- [ ] 计算机层次结构：高级语言 → 汇编 → OS → 指令集架构 → 微架构 → 数字逻辑

## 复习策略建议

1. **优先吃透流水线**：数据冒险→转发→stall→时空图，这是两年分值最高的大题，还出现原题复用
2. **Cache 地址划分要会算**：组相联、直接映射切换时 Tag/Index/Offset 位数变化
3. **MIPS 汇编不能丢**：C 转汇编、机器码格式、beq 偏移计算
4. **单周期控制信号烂熟**：lw/sw/beq/R-type 各信号值随口能说
5. **第九章不要赌它不考**：2024 试卷缺页，且传统上中断是独立大题
