## 第一章：计算机系统概论（10-15分）

- **简答题**：可执行文件在计算机上的执行过程、对计算机层次结构的理解（开放性）
- **计算题**：CPI、MIPS 数、CPU 执行时间、平均访问时间（套公式，送分题）

## 第二章：数据表示（10-15分）

- **整数**：真值与机器数之间的转换
- **IEEE 754 浮点数**（重点，必练熟）：
  - 32位 float 的编码转换（符号 + 阶码 + 尾数三块分别编码）
  - 机器数结果写 **16进制**，真值结果写 **10进制**
  - 特殊数表示（非规格化数等）
  - 曾考过变形（10位、12位），但近年都考标准 float

## 第三章：运算器（10-15分）

- 补码的整数加减运算
- **判溢出**（四个标志位 CF/ZF/SF/OF）：含义、如何计算、如何用于判溢出

## 第四章：存储器（10-15分）

- ⚠️ **本次不考** 存储器芯片扩展（位扩展/字扩展/字位同时扩展）
- 重点是 **Cache** 和**虚存管理**：
  - Cache 容量、命中率/缺失率、平均访问时间、访问效率
  - **易错点**：缺失时访问时间 = **tc + tm**（不是只有 tm），教材习题详解答案有误
  - 访问效率（e = tc / ta）≠ 访问速度提高（tm / ta），公式不同
  - 分页式虚存地址转换、缺页异常处理（查表题，送分题）

## 第五章：指令系统 ⚠️ 本次变化最大

- **不再考** MIPS 指令系统各字段记忆
- **转向考**：指令系统设计 + 寻址方式
  - 扩展操作码设计，计算某类指令的最大条数
  - 各类寻址方式填表（有效地址 E、操作数的值）
  - 给定配置，设计指令格式
  - **PC 相对寻址**（课上反复强调的重点）
  - 结合 C 代码、寄存器/内存状态分析指令执行结果
  - 设计指令序列实现要求的功能

## 第六章：单周期 CPU（10-15分）

- **故障分析题**：
  - 控制信号恒0/恒1故障，分析对哪些指令有影响
  - 数据通路中移除/修改某元件，分析问题并修改
- **基础要求**：必须熟练掌握 MIPS 单周期数据通路，课上讲的7条经典指令每一条的：
  - 数据通路怎么走
  - 各控制信号取什么值

## 第七章：流水线 CPU（10-15分）⭐ 重点难点

冒险类型与气泡对照表：

| 冒险类型 | 气泡流水线 | 重定向（转发）流水线 |
|---------|----------|------------------|
| 普通数据相关（相邻指令） | 插 2 个气泡 | 已消除 |
| 普通数据相关（中间隔1条） | 插 1 个气泡 | 已消除 |
| Load-use 相关 | 插 2 个气泡 | 插 1 个气泡 |
| 分支冒险 beq/bne（满足跳转时） | 冲刷 2 条，损失 2 时钟 | 同左 |
| 无条件跳转 j | 每次损失 2 时钟 | 同左 |

### 关键要点

- 理想流水线执行时间：5 + (指令数 - 1) 个时钟
- 实际执行 = 理想 + 额外的气泡/阻塞时钟
- **循环体分析**：beq 只有最后一次满足跳转时才损失2时钟，j 每次循环都损失2时钟
- **⚠️ 特殊前提**：如果题目说"同一寄存器的读和写不能在同一个时钟内完成"
  → 相邻数据相关插 **3个气泡**（不是平时的2个），因为要多等一个写回周期
- 题干可能很长，不要怕，题目越长往往越简单

## 第九章：中断系统（10-15分）

- **中断屏蔽技术**：
  - 给定优先级 → 设置中断屏蔽字
  - 给定屏蔽字 → 判断处理优先级
  - 给定中断请求情况 → 画 CPU 中断响应轨迹图
- **计算分析**：轮询/中断/DMA 方式下，CPU 对外设的时间开销及时间占用率
- **简答**：单级中断 vs 多重中断的执行流程

## 开放题（可能结合在章节题中）

- CPU 各组成部分采用什么技术提升性能
- 这些技术手段产生的条件是什么
- 提升了什么性能，是否有其他代价
- 这些技术革新思路给我们带来什么启发

## 复习优先级建议

1. **第七章 流水线** — 最难，必考，先攻克（气泡/转发/load-use/分支）
2. **第五章 寻址方式 + 指令设计** — 今年新变化，重点准备
3. **第六章 故障分析** — 理解数据通路是基础
4. **第二章 IEEE 754** — 计算熟练度，不要丢分
5. **第四章 Cache 计算** — 公式记牢，注意 tc+tm
6. **第九章 中断屏蔽字** — 两种题型（屏蔽字↔优先级）都要会
7. **第一章 + 第三章** — 相对简单，确保拿满
