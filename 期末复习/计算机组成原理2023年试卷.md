## 三、（15 分）

以下C语言程序段中有两个函数 sum_array 和 compare, 假定 sum_array 函数第一个被调用, 全局变量 sum 分配在寄存器 $s0 中。要求写出每个函数对应的MIPS汇编表示, 不支持使用伪指令。

```c
int sum = 0;
int sum_array(int array[], int num)
{
    int i;
    for (i = 0; i < num; i++)
        if compare(num, i+1)  sum += array[i];
    return sum;
}
int compare(int a, int b)
{
    if (a > b)
        return 1;
    else
        return 0;
}
```
